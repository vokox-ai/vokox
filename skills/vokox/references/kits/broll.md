# Kit: B-roll (silent supporting footage)

Use with `auto:video.hq` or `auto:video.fast`; refs = `["@frame"]` (a generated or supplied still).

```
Create a silent B-roll micro-shot from the reference image. {camera move: "slow push in" |
"handheld follow" | "static locked-off" | "gentle orbit"}. {one action: "steam rises from the cup
while a hand turns it a quarter turn" | "fingers scroll the phone screen"}. {material mode:
"practical real footage, natural light" | "product beauty, studio light, soft reflections" |
"screen demo, UI clearly readable"}. People, if visible, perform the action and do not speak to
camera. Background stays as in the reference. No on-screen text.
```

Slots: `{camera move}`, `{one action}`, `{material mode}`. 5 s default. Chain 3–4 B-roll shots
under one voice-over; vary the camera move between consecutive shots.
