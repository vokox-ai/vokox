# Kit: B-roll (supporting footage under a voice-over)

Use with `auto:video.hq`, `seedance-2-mini` or `auto:video.fast`; refs = `["@frame"]` (a generated
or supplied still). Set `audio: false` when a voice-over will play on top.

```
Short supporting shot animated from @image1; keep its people, product, place and light as they
are. {camera: "locked, framing unchanged" | "slow push toward {what matters}" | "handheld follow
beside the subject" | "slow quarter orbit around the product" | "selfie arm-length, natural bob"}.
{cause + action + end state: "a hand lifts the lid, steam curls up from the pot, the lid comes to
rest on the counter" | "a thumb scrolls the order list, stops on the delivered item"}.
{look: "everyday phone footage, daylight" | "product close-up, soft studio light, gentle
reflections" | "phone screen filmed over the shoulder, interface stays on the device" | "receipt /
review / chart as a real object on a desk"}. Anyone visible is busy with the action and does not
talk to the camera. Keep it subtitle-free; labels and screens already in the image stay attached
to their objects.
```

Slots: `{camera}`, `{cause + action + end state}`, `{look}`. 5 s default; the edit may use only
the first 2–3 s.

Picking shots for a voice-over:
- **Exact** when the line names something the viewer must see: one clip per claim, cut on the word.
- **Montage** when the line describes a habit or mood: 2–4 short clips, nouns need not hit cuts.
- Vary the camera between neighbouring clips (locked → push → handheld), and keep the same key
  frame family so the world stays one world.
- Motion level: tiny for proof and screens, readable for everyday actions, big (splash, burst)
  only when the frame already holds the thing that bursts.
